# Сервер обсерватории

## Что это такое

Простое спринг приложение для поиска телескопов поставленных дома и работающих с прогой из соседнего репозитория.
Для работы системы нужно поставить прогу на комп для управления. Серверную прогу с доступом в сеть. Прогу на телескоп
с доступом к локальной сети. После успешного запуска серверное приложение само обнаружит телескоп и сможет передавать
на него команды для управления.

Параметры:
- SERVER_KEY - секретный ключ который будет использоваться как пароль для входа
- POINT_NAME - название точки, которое будет отображаться в приложении

## Сборка образа и запуск контейнера

В папке рядом с Dockerfile должен лежать server.xml с версией сервера и server.properties с настройками сервера.

Сборка образа:

    docker build . -t ghcr.io/jutterdev/star-view-server:1.0.0

Запуск контейнера:

     docker run -d -it -p 8080:8080 -e SERVER_KEY="12345678" -e POINT_NAME="station-north-02" -v --restart=always --name server-view ghcr.io/jutterdev/star-view-server:1.0.0

Выгрузка контейнера в пакеты гитхаба:

     docker push ghcr.io/jutterdev/star-view-server:1.0.0

Обновление контейнера через пакеты гитхаба:

     docker pull ghcr.io/jutterdev/star-view-server:1.0.0
